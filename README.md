# Brick Archivio

App Android personale per catalogare la collezione LEGO® fotografandola.

- Fotografi uno o più oggetti (scatole, set montati, minifigure, pezzi): l'app individua
  gli oggetti, li riconosce e li aggiunge al catalogo.
- Ogni oggetto contiene l'immagine ufficiale, i dati ufficiali (nome, anno, tema, pezzi),
  le tue foto, prezzo, data e luogo d'acquisto, note e tag.
- Tutto resta sul telefono; internet serve solo per riconoscere e scaricare i dati.

## Installazione

1. Apri **Releases** di questo repository dal telefono e scarica l'ultimo `BrickArchivio-N.apk`.
2. Installalo (consenti l'installazione da browser/File se richiesto).
3. In **Impostazioni** inserisci la tua chiave API gratuita di [Rebrickable](https://rebrickable.com/api/).
